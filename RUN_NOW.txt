================================================================================

================================================================================

================================================================================
                        TO STOP THE SERVER
================================================================================

Press: Ctrl + C (or Cmd + C on Mac)

================================================================================
                        IF PORT 5173 IS IN USE
================================================================================

The server will use next available port (5174, 5175, etc)
Just open the URL it shows in the terminal.

OR stop other server:

Windows:
  netstat -ano | findstr :5173
  taskkill /PID <PID> /F

Mac/Linux:
  lsof -ti:5173 | xargs kill -9

Then run: pnpm dev

================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: White blank page
FIX: Wait 10 seconds and refresh (Ctrl+R)

PROBLEM: "Cannot find module"
FIX: Run: pnpm install

PROBLEM: Products not showing
FIX: Open DevTools (F12) → Console tab
     Check for error messages
     Should see: [v0] Products data: Array(...)

PROBLEM: 401 Unauthorized errors
FIX: Your Supabase RLS is blocking access
    Go to: https://app.supabase.com
    SQL Editor → Run this:
    ALTER TABLE public.products DISABLE ROW LEVEL SECURITY;

PROBLEM: "pnpm not found"
FIX: npm install -g pnpm
