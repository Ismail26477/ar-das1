================================================================================
                      WHAT YOU RUN (SIMPLE)
================================================================================

Just this command:

  pnpm dev

That's it! This starts everything you need:
  ✅ Frontend server
  ✅ Database connection
  ✅ API integration
  ✅ Hot reload (auto-refresh on code changes)

NO BACKEND SERVER TO RUN SEPARATELY!

================================================================================
                          DATA FLOW
================================================================================

1. You type: http://localhost:5173/ in browser
   
2. Vite dev server sends React components to browser
   
3. Dashboard loads (Products, Orders, Customers pages)
   
4. User clicks "Products" page
   
5. Component calls: useProducts() hook
   
6. Hook makes request to Supabase:
   SELECT * FROM products
   
7. Supabase sends data back
   
8. React renders the data on page

All of this happens with just: pnpm dev

================================================================================
                      COMMANDS EXPLAINED
================================================================================

pnpm dev
  │
  ├─ Starts Vite development server
  ├─ Opens connection to Supabase
  ├─ Watches for file changes
  ├─ Auto-reloads browser when you edit code
  └─ Shows at: http://localhost:5173/

pnpm install
  │
  ├─ Downloads all dependencies (npm packages)
  ├─ Creates node_modules folder
  └─ Only needed once (or if dependencies change)

pnpm build
  │
  ├─ Creates optimized production version
  ├─ Minifies code
  ├─ Generates dist/ folder
  └─ For deploying to production

pnpm lint
  │
  ├─ Checks code for errors
  ├─ Checks code style
  └─ Doesn't run the app

================================================================================
                      ONLY RUN pnpm dev!
================================================================================

Everything else (database, API, authentication) is handled by Supabase.

You don't need to:
  ✅ Install a database
  ✅ Set up a backend server
  ✅ Configure ports
  ✅ Set up authentication
  ✅ Deploy infrastructure

Supabase handles all of that for you in the cloud!

================================================================================
                      STEP BY STEP
================================================================================

1. Open terminal/command prompt

2. Type: cd ar-das1

3. Type: pnpm install
   (Only first time, or if you add new packages)

4. Type: pnpm dev

5. Wait for: "VITE v5.x.x ready in XXX ms"

6. Open browser to: http://localhost:5173/

7. Click on "Products", "Orders", "Customers" in sidebar

8. See your data from Supabase!

9. Edit a file (like Products.tsx)

10. Browser auto-refreshes with your changes

That's your development workflow!
